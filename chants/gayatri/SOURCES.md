# Gāyatrī mantra — sources and credits

## Text
Ṛgveda 3.62.10 (seer Viśvāmitra Gāthina, deity Savitṛ, metre gāyatrī), with the three vyāhṛtis
(*oṃ bhūr bhuvaḥ svaḥ*) prefixed as in daily recitation (Taittirīya tradition).
